# Skillpath-framer-assignment
Skillpath — Framer Assignment for Junior Developer Role @WebVeda

Working Link - https://similar-stegosaurus-860298.framer.app/

## CourseSection

The CourseSection is implemented as a React component in Framer.

### Features

- Live course data from the assignment API
- INR/USD currency handling
- Loading state
- Error state with retry
- Empty state
- Country API failure handling
- Responsive 3/2/1 course grid
- Framer property controls
- Search
- Price sorting
- Refundable badge
